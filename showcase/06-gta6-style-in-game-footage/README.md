# GTA 6 Style In-Game Footage

![A beach scene rendered with a video-game interface overlay](preview.jpg)

An in-game screenshot of an open-world game: low-poly water, a chase framing, and a HUD laid over the top. Use it for game key art, gameplay-style marketing, and mock screenshots where the interface has to look real.

## Try the prompt

```text
GTA 6 in-game footage, very detailed, very realistic. Close-up shot taken from a stationary 4k monitor. (There's a slight blurriness in the image, as it feels like it was taken handheld). A wide, bright environment. Realistic details. The character is walking on the beach with / :dog.
```

[Copy plain text](prompt.txt) · [Full-size image](full.jpg)

## Make it your own

- **Name the game feel, not the game.** The source prompt names a specific title; swap it for a genre — `open-world crime game`, `1990s arcade racer` — and you keep the look without the trademark.
- **Specify the HUD or you will not get one.** Interface elements are the difference between a game screenshot and a landscape photograph.
- **Decide the subject before you ship it.** This render drifted to a beach scene with a swimwear figure, which is a subject choice neither the prompt nor the brief implied.

## Settings and result

`openai/gpt-image-2.5-flare` · quality `xhigh` · 16:9 · **2459 image tokens** · 24 s · $0.0741

**This is the weakest card in the set and it is worth saying so.** The prompt named a specific game title; the render came back as an open-world beach with an interface overlay. It reads as generic third-person game footage rather than the scene the title implies, and the figure it chose makes it unsuitable for a repository front page.

Kept in the set rather than re-rolled because it demonstrates a real failure mode: **naming a game gets you the genre's texture, not its identity.** For a specific look you have to describe the geography, the camera and the HUD yourself.
