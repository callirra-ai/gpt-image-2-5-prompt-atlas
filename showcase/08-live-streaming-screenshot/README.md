## Try the prompt

```text
Generate a screenshot of a TikTok live stream featuring a woman streaming.
```

[Copy plain text](prompt.txt) · [Full-size image](full.jpg)

## Make it your own

- **Describe the UI furniture, not the app.** Live badge, viewer count, comment ticker, gift row. Name the parts and the model builds a believable interface.
- **Give the host something to hold.** A sign, a product, a card. It gives the frame a reason to exist beyond a portrait.
- **Render only the strings you want.** List them. Otherwise the model fills the ticker with invented usernames and the screenshot stops being reusable.

## Settings and result

`openai/gpt-image-2.5-sunburst` · quality `xhigh` · 9:16 · **2459 image tokens** · 47 s · $0.0739

The interface came out complete and correctly ordered: pink `LIVE` badge, `1.0K` viewers, a scrolling comment column, a gift icon row along the bottom, and a host mid-speech in a home studio.

**The source prompt was adapted.** The original wording — `a beautiful woman streaming` — was rejected by OpenAI's safety system when routed through OpenRouter (`safety_violations=[sexual]`). Removing the adjective was enough. The original wording is recorded in `source.json` under `adaptation`.
