## Make it your own

- **The joke is the collision.** A modern app shell plus an entirely historical content set. Change the dynasty, the poets or the platform; keep the two halves.
- **Write the post yourself.** The model will invent something plausible, but the line is the punchline — `Just arrived in Huangzhou, demoted but feeling okay` is doing more work than any styling instruction.
- **Ask for the interface to be replaced, not decorated.** Like icons swapped for dynasty patterns is what sells it.
